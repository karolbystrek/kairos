# Issue tracker: GitHub

Track issues, specifications, and progress in GitHub Issues for
`karolbystrek/kairos`. Use `gh` for all GitHub operations.

- Publish a ticket: `gh issue create`.
- Read a ticket: `gh issue view <number> --comments`.
- List progress: `gh issue list`.
- Update progress: `gh issue edit`, `gh issue comment`, and `gh issue close`.
- For multiline bodies, use `--body-file`.

PRs as a request surface: no.
